요약 평가

항목평가비고
레이어 분리우수Core / Combat / UI / Backend / Ads 가 명확히 구분
Facade 적용우수GameFacade가 8개 매니저 위에서 중앙 허브 역할 수행
Object Pooling양호Dictionary<Enum, NewPool> 기반 O(1) 접근
이벤트 기반 통신양호OnLevelup, OnTimeUp, OnHpChanged 등 Action 다수 활용
네이밍 일관성개선 필요New* 접두사, prefebs 오타, CatAtack, Achive 등
MVP 분리 (UI)부분 적용설계 문서에는 명시, 실제는 View ↔ Manager 직접 호출이 다수
레거시 코드정리 필요Old/ 폴더가 동일 책임의 클래스를 중복 보유
정적 의존성주의GameFacade.Instance에 모든 시스템이 의존 → 테스트 어려움

클래스 다이어그램 - 주요 관계 (Mermaid)

실선 = 직접 참조 / 호출 · 점선 = 이벤트 구독 · ◆ = ScriptableObject · ★ = Facade · ● = Singleton 

classDiagram
  direction LR

  class GameFacade {
    +Instance$
    -NewGameManager gm
    -NewPlayerManager pm
    -NewItemManager im
    -TimeManager tm
    -NewAudioManager am
    -NewObjectPoolManager pool
    -NewUIManager ui
    -LifeManager life
    +GameStart()
    +PlayerExpAdd()
    +PlayerTakeDamage()
    +GameOver()
    +Get~T~(T key)
    +Return~T~(T key, GO)
  }

  class NewGameManager {
    +isLive
    +Stop() Resume()
    +GameVictory() GameOver()
    «event» OnStop OnResume
    «event» OnGameOver OnGameVictory
  }
  class NewPlayerManager {
    -float _playerHp
    -int _level _exp _kill
    +AddExp() AddKill()
    +TakeDamage() HealFull()
    «event» OnLevelup OnHpChanged
  }
  class TimeManager {
    +GameTime
    «event» OnTimeUp
  }
  class NewItemManager {
    +ItemData[] itemDatas
    +NewWeapon[] weapons
    +Gear[] gears
    +SelectItem(idx)
  }
  class NewObjectPoolManager {
    +Instance$
    -Dictionary~EnemyEnumId,NewPool~
    -Dictionary~WeaponEnumId,NewPool~
    -Dictionary~ItemEnumId,NewPool~
    +Get() Return()
  }
  class NewAudioManager {
    +PlayBgm() PlaySfx(Sfx)
  }
  class NewUIManager {
    +Win() Lose()
    +PauseAndResumeButtonShow()
  }
  class LifeManager {
    +CurrentLife
    +ConsumeLife() AddLife()
    «event» OnLifeChanged
  }

  class NewPlayer {
    -inputVec
    -Scanner scanner
    -CharacterSO currentCharacterSO
    +OnMove()
  }
  class NewWeapon {
    +Init() Fire() LevelUp()
    «event» OnWeaponChanged
  }
  class CatAttack {
    +damage per speed
    +Init()
  }
  class Scanner { +GetNearest() }
  class Gear {
    +ApplyGear()
    «event» OnApplyGear
  }
  class MagnetPuller
  class NewCharacter {
    «static» Speed Damage WeaponSpeed
  }

  class NewEnemy {
    +Init(NewSpawnData)
    +Dead() DropItems()
  }
  class NewPickupItemBase {
    «abstract» OnCollected()
  }
  class ExpItem
  class NewHealItem
  class NewMagnetItem
  class NewItem { +Setup() +OnClick() }

  class CharacterSO {
    «SO»
    +characterID
    +characterSpeed damage
    +CharacterUnlockCondition condition

  class ItemData {
    «SO»
    +itemType
    +damages[] speeds[] counts[]

  class NewSpawnData {
    «SO»
    +enemyHp enemySpeed spawnTime
  }
  class PoolItemDataBase {
    «SO»
    +List~NewPoolItemData~ items
  }
  class NewPoolItemData { «SO» }

  class NewLevelUpView { +Show() Hide() Next() }
  class NewResultView { +Win() Lose() }
